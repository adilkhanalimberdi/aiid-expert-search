# Surface: Sarap web app (Search, Data, Analytics)

Mode: operate. Audience: AIID hackathon jury on a laptop or projector, then AIID staff. Job: type a need, get ranked experts with checkable reasons.

## Direction contract

THESIS: The query is laid out as smalt tesserae: every term, city and condition the engine read becomes a coloured tile, and each expert's score is set in a 10×10 tile field. Refuses the category default of a white SaaS list with a blue pill and a progress bar.

OWN-WORLD: Almaty modernist mosaic. Smalt ultramarine shell, concrete-grey ground, turquoise, ochre and terracotta tiles, near-black grout lines. Wide modernist display (Unbounded), Golos Text for UI. Square tiles with 2px grout gaps, no radii, no shadows except the query slab.

STORY: The jury types a request, sees exactly how it was read (tiles), sees the best expert with the score as a filled mosaic and reasons from real fields, compares two more fits and the rest, and trusts that weak results look weak.

FIRST VIEWPORT: Smalt header with nav, language switch and Sarap | AIID lock-up; large modernist title; query slab full width of the column with the ochre action; examples below; synthetic-data notice strip. After search: tile readback row, then the best-candidate panel (name left, 10×10 score mosaic and reasons right).

FORM: Smalta (Almaty modernist mosaic), position 3 of 7 on own list; seed:18552483cc0ac58d. Raises: Datamatics numeric density (tabular figures), Acetate state vocabulary (found, related, missing, excluded as four tile states).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
